# ProgramlamaSanatiDisketleri

Programlama Sanati PcWorld dergisinin verdiği Disket Dergidir. Burada bu disket derginin sayılarının bazıları zip dosyası halinde bulunmaktadır. 
Bu dergiler eski olup içerisinde eski 16 bit Windows ve Dos uygulamaları vardır. Ayrıca çeşitli dillerde programlama örnekleri de bulunmaktadır.

Nostalji sevenler dosyayı indirip inceleyebilirler. Eski programlar buradaki EskiProgramBaslatici kısmındaki
Gui program ile denenebilir.

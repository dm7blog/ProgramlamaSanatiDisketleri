# ProgramlamaSanatiDisketleri

Programlama Sanati adlı eski Disket Derginin eski sayılarının bazıları zip dosyada bulunmaktadır. Bu dergiyi eski olup içerisinde eski 16 bit Windows ve Dos uygulamaları vardır. Ayrıca çeşitli dillerde programlama örnekleri bulunmaktadır.

Nostalji sevenler dosyayı indirip inceleyebilirler. Eski programlar buradaki EskiProgramBaslatici kısmındaki
Gui program ile denenebilir.
